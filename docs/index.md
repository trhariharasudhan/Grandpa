# Grandpa

Grandpa is a privacy-focused local Windows AI assistant designed to control
applications, windows, files, keyboard, mouse, screen interactions, and system
operations through natural-language voice and CLI commands.

## Start Here

```powershell
git clone https://github.com/trhariharasudhan/Grandpa.git
cd Grandpa
uv sync --extra voice --extra screen --extra server
ollama pull qwen2.5:3b
uv run grandpa doctor
uv run grandpa chat
```

Use `uv run grandpa voice` for local microphone input and
`uv run grandpa voice-operator` for action-first voice control.

## Core Capabilities

- Local Ollama chat and intent routing
- Push-to-talk voice, wake phrases, local STT, and Windows TTS
- Windows application and window control
- Permission-aware keyboard and mouse automation
- Screen capture, OCR, description, and element location
- Safe local file and folder operations
- Process and system diagnostics
- Confirmation, policy enforcement, and audit logging

## Safety

Grandpa does not execute arbitrary shell text generated by a model. Actions are
parsed into typed requests, checked against policy, and confirmed when risk is
destructive, authentication-related, financial, or system-wide.

## Interfaces

The supported user interfaces are the CLI, interactive chat, and local voice
runtime. The optional FastAPI server remains available for trusted local API
clients.
