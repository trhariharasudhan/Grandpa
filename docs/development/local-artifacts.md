# Local Generated Artifacts

These paths are generated by Python, Rust, documentation, packaging, tests, or
the local assistant runtime and should not be committed.

| Artifact | Source |
| --- | --- |
| `.uv-cache/` | Local uv package cache |
| `.coverage` | Coverage result |
| `site/` | MkDocs output |
| `target/` and `rust/target/` | Rust builds |
| `dist/` | Python distributions |
| `__pycache__/` and `*.pyc` | Python bytecode |
| `.pytest_cache/` | pytest cache |
| `.ruff_cache/` | Ruff cache |
| `logs/`, `*.log`, and `runtime/` outputs | Local logs, reports, and state |

Do not remove local databases, credentials, logs, models, or runtime state as
part of source cleanup. Confirm the exact path and owner before deleting any
generated artifact.
