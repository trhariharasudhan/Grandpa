# Local Memory

Grandpa uses local memory to retain useful personal facts, preferences,
projects, and recent conversation context.

In chat:

```text
remember my name is Hari
show my memories
forget my name
/memory list
/memory search vscode
```

Default listing hides internal workflow records. Use `/memory all` only when
diagnosing local state.

Memory remains on the machine. It is not uploaded to an analytics service or a
cloud model. Avoid deliberately saving passwords, access tokens, OTPs, payment
card data, or private keys.
