# Windows Automation

Grandpa can open and focus applications, manage windows, type text, press keys,
move and click the mouse, and perform bounded file or process operations.

```powershell
uv run grandpa apps scan
uv run grandpa automation --help
uv run grandpa screen active
```

Natural commands in chat or voice reuse the same typed action and permission
path. Grandpa does not execute arbitrary command-prompt or PowerShell text
generated by a model.

Low-risk navigation can execute directly. Deletion, power operations,
authentication, purchases, secrets, and other sensitive actions require
confirmation or are blocked.
